# Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Compact, a free macOS menu bar camera app with snaps, mic check, a floating shaped
window, notch trigger, shortcut, and a new local vlog recorder.

**Architecture:** A Swift package with two targets. `CompactCore` is a library of pure, unit-tested
logic: settings, file naming, geometry, audio math, and recording state. `Compact` is the executable,
holding AppKit, SwiftUI, and AVFoundation code that uses the core. `scripts/build-app.sh` wraps the
release binary into an ad-hoc-signed `build/Compact.app`. Hardware behavior (camera, mic, windows) is
verified by building and launching the app.

**Tech Stack:** Swift 6.1 (command-line tools, no Xcode), SwiftPM, SwiftUI + AppKit, AVFoundation,
ServiceManagement, Swift Testing, sindresorhus/KeyboardShortcuts 2.x.

**Spec:** `docs/superpowers/specs/2026-11-25-compact-design.md`

## Global Constraints

- Platform floor: `.macOS(.v14)` in Package.swift; `LSMinimumSystemVersion` = `14.0`.
- Bundle ID `com.compact.app`, name `Compact`, executable `Compact`, `LSUIElement` = true (no Dock icon).
- `NSCameraUsageDescription` = "Compact shows your camera so you can check yourself before a call."
- `NSMicrophoneUsageDescription` = "Compact uses the microphone for the mic check meter and to record vlogs."
- Snaps → `~/Pictures/Compact/`, vlogs → `~/Movies/Compact/`, created on first save.
- File names: `Compact Snap yyyy-MM-dd 'at' HH.mm.ss.png` / `Compact Vlog yyyy-MM-dd 'at' HH.mm.ss.mov`, suffix ` (2)`, ` (3)`… when taken.
- Preview mirrored by default; saved snaps and vlogs are never mirrored.
- The camera runs only while the popover or floating window is visible, or while recording.
- No Hand Mirror code, assets, fonts, or name. Snap caption font: "Marker Felt".
- Only external dependency: `https://github.com/sindresorhus/KeyboardShortcuts` from `2.0.0`.
- All commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Camera and microphone permission dialogs are clicked by the user, never by the agent.

## Review Focus

1. **Camera denied, missing, or busy:** the panel shows a plain message and an "Open System Settings" button, never a black box. Test: `CameraAccessTests` in Task 2.
2. **Popover closes or app quits mid-recording:** recording continues when the popover closes. Quit waits for the file to finish, so the `.mov` plays. Tests: `shouldRunCamera` cases in Task 2, `RecordingState.isActive` in Task 7, plus a manual quit-while-recording check in Task 7.
3. **Save folder missing or not writable:** the folder is created, and a write failure shows an alert instead of failing silently. Test: `uniqueURLCreatesFolder` and `uniqueURLThrowsWhenUnwritable` in Task 4.
4. **Mac without a notch, or the notch display unplugged:** the notch toggle is disabled with an explanation, and no invisible window is placed. Test: `notchRectNilWithoutAuxAreas` in Task 9.
5. **Camera light left on:** closing the popover or floating window stops the session within about a second unless recording. Test: `shouldRunCamera` table in Task 2, plus the manual green-light check in Task 2.
